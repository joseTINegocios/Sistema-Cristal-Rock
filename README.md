# Ejecuta e implementa tu app de AI Studio

## Ejecutar Localmente

**Requisitos previos:** Node.js


1. Instala las dependencias:
   `npm install`
2. Configura la `GEMINI_API_KEY` en [.env.local](.env.local) con tu clave de API de Gemini
3. Ejecuta la app:
   `npm run dev`
